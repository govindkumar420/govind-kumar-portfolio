## Important
Replace the placeholder GitHub and LinkedIn URLs in `index.html` with your real profile URLs.

## Add a photo
Place your professional photo in `assets/profile.jpg`, then replace the `GK` text inside `.profile-photo` with:
`<img src="assets/profile.jpg" alt="Govind Kumar">`

## Deploy on GitHub Pages
1. Create a repository, e.g. `govind-portfolio`.
2. Upload all files/folders.
3. Settings → Pages.
4. Deploy from `main` branch → `/root`.
5. Open the generated Pages URL.
